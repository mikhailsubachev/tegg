Components · proposal

One card for every object

A single card built only from attributes every object has: title, tags and content, plus its type’s icon (FR-TYP-08; objects have no icon or cover of their own, D-217). It works for any type, including user types and plain Obsidian files with no frontmatter. Type-specific properties are an optional extra slot, not part of the base card.
