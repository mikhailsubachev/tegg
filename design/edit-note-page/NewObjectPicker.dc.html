Behaviour
  • One picker for every “New object”. ⌘N, the sidebar’s New object button and the palette’s New object… open it. A type page’s New <Name> and the palette’s New <Name> still create at once: the type is already known.
  • The default type is preselected (FR-VLT-05) and marked Default, so ⌘N ⏎ is still the old one-step path.
  • Same types and order as the Type menu (D-550): Page, Task, Quick Note, then your types A–Z. Daily Note, Tag, Image and PDF are not offered (they have their own ways in).
  • Typing filters by the start of any word of the name, case- and accent-insensitive; the first match is selected. ↑/↓ move, ⏎ creates, Esc closes and returns the focus. A click on a row creates.
  • Then as today (D-520, D-367): the new, unsaved object of that type opens with its Title field in edit mode; nothing is written until the first change.
  • Where it opens: ⌘N and the palette show it at the palette’s place (top centre of the window); the button shows it right under itself.
