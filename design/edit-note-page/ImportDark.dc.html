Importing from Capacities and Obsidian

A check of the import requirements, then the import as a step-by-step window: choose the source, map it, preview it, import, read the report. Nothing is written before the preview is confirmed.

What the requirements say

  • Capacities import is in the MVP (FR-IMP-03, D-41), built in MS7 after the daily-use point (D-375).
  • Obsidian: open in place or copy with a type-mapping wizard (FR-IMP-01, D-36). Moved to v1.0 (D-373).
  • Notion and Anytype are v1.x (FR-IMP-02, -04); Kindle/Readwise is out (FR-IMP-06).
  • Every import: zip or folder input with progress and cancel (-07), mapping of types, attributes and values (-08), a preview before writing and a report as a Page (-05, -19).
  • One Capacities space per run (-22, D-44). One-time import; a repeat warns about duplicates (-20, D-49).
  • Into a non-empty vault a backup zip is made first; a new vault is the recommended default (FR-HIS-04 AC-1, D-57).
  • Opening a folder that isn’t a Tegg vault asks whether to import it; nothing is written before confirming (D-91).

Gaps and proposals needs your decision

  • No screen flow is defined. The step order, the entry points (File › Import…, palette) and the separate “things to decide” step are my proposal.
  • Query stubs: FR-IMP-16 says “saved-query stubs”, §11.1 says Pages flagged “needs rebuilding”. I drew Pages. With queries now living as blocks in notes, the stub could be a Page holding an empty query block.
  • Open in place: not stated whether Tegg may add a .tegg/ folder to an Obsidian vault, or whether a backup is made. I drew: adds .tegg/, no backup.
  • Rule order when a folder rule and a tag rule both fit a note is not defined. I drew: top rule wins, rules can be dragged.
  • Obsidian-only content (canvas files, plugin blocks such as Dataview) is not covered. I drew: copied or shown as code, and listed in the report.
  • Plain Markdown folders: D-93 gave them to the Obsidian importer; D-373 moved that to v1.0. I show one source, “Obsidian vault or Markdown folder”.
  • Where the report Page is saved and its name are not stated. I drew “Import report · date”.
  • Checklist → Task conversion on import (FR-IMP-18) is v1.0 and not drawn.
