What this page is
  • Every Settings section as built in the app today (app/ui/src/pages/SettingsPage.tsx, settings5b.tsx), with the labels, notes and defaults the app uses. Values shown are the defaults; the location and backups are invented (D-62).
  • The settings routes have no design board yet (design: null in the registry), so this is the first one.
Gaps against the BRD
  • FR-SET-02: font, font size and accent color are v1.0 (D-565); editor width is now the vault’s Page width.
  • FR-SET-04: shortcuts are read-only until v1.0 (D-376, D-548).
  • FR-SET-06: Trash and history is a placeholder (v1.0).
