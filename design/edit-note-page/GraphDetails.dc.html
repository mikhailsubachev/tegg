  • Tags are pills with “#name” inside, not circles, so a tag never reads as an object. Fill = the tag colour’s tint, border and text = the colour (the 8 type colour tokens, R14).
  • None (the default) is the neutral chip: white fill, grey border, grey text, the same as the tag chip in notes.
  • Edges to tags are dotted and thin; the Tags type filter and the “Tags” connection toggle hide them (FR-GRP-08).
  • Tag nodes use the tag’s colour from the start (D-707, D-275: the graph is v1.0).

  • With “Hover to preview” the hovered node’s ring fills during the delay (the setting’s value, e.g. 400 ms), then the standard preview appears beside it, without moving the selection.

  • Every node is focusable; the focus ring is the system focus colour with a 3 px gap, so it reads on any type colour and on selection.
  • Arrow keys move to the nearest node in that direction; VoiceOver reads title, type, connection count, how it is linked to the centre, and position (“2 of 9”).
  • List is the text alternative: the same neighbourhood as a tree (depth = indent, link kind in words). VoiceOver announces that it is available when focus enters the graph (FR-UX-08).

  • Presets are one list shared by the panel and the full view; picking one sets that view’s filters only (FR-GRP-02).
  • Default is built in (all types, all connections): it can be applied, not renamed or deleted.
