G · When + doesn’t open the menu

Only at the start of a block or after a space
  • + then a space at the start of a line: the menu closes and the line becomes a bulleted list, as today.
  • Inside a word: C++, 1+1, a+b type a plain +.
  • Not in code blocks, inline code, the title field, or the mindmap node field.
  • Esc closes the menu and leaves + and the query as typed text; Backspace over the + closes it.

H · Keys

Shared with the / menu
  • ↑ ↓ move the selection, ⏎ chooses, Esc closes, the pointer hovers and clicks.
  • A New <type> row never converts the current block. The old Task row is gone (/task finds New Task); Turn into object… and ⇧⌘T, ⇧⌘O still convert and leave an embed.
  • Rows list the types a new object can have: never Daily Note, Tag, Image, PDF.
