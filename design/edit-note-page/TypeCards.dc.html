Added 2 Oct
  • One card for all types, the same as the Tasks Schedule card: lead (type icon, or the checkbox for Task) and title with ⋯, grey #tags, the body clamped to 2 lines, property pills, and a footer with one link chip and a date.
  • The title is always shown; each type picks which properties its card shows, on the Object settings page (Card section). Empty parts take no space, so a card with only a title is one line high.
  • Files (Image, PDF) add a preview strip at the top; no object icon or cover (D-217). Review workflow types show an amber Unreviewed pill until reviewed (FR-TYP-12).
  • Used everywhere a card appears: board views, card embeds (FR-EMB-02), previews, Pinned. All names are invented (D-62).
