Link chip variants

One chip, a few states. The base is always the same: type icon + title on a light tint, inline with the text. Extra state is added at the end of the chip, never in front of the title, so links stay readable in a sentence.

  • Task suffix order: due date (only when set) · status. Status always shows, so a task chip is never mistaken for a page link.
  • The suffix is 12 px and separated by a thin divider; the whole chip stays on one line and truncates the title, not the suffix.
  • Unreviewed only applies to types with the review workflow on (always Quick Note and Daily Note, FR-TYP-12).
