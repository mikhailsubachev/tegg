### R44. Derived values (FR-TSK-01…03, -09; AP-401, AP-402, AP-407, AP-414)

- **Is a task:** an indexed object whose `type` resolves to `task` (FR-TYP-13 AC-1), not in `_templates/` or `.trash/` (FR-TPL-07, D-102). Folder, other keys and checklist syntax never make a task (FR-TSK-11).
- **Semantic state:** the `state` of the option whose label equals the `status` value (NFC, exact, as types.md R10 `select`). Missing `status`, a value that isn't an option, an option without `state` or with an unknown `state` → Open (AP-401). Values are never rewritten by reading.
- **Valid `due`:** a calendar date `YYYY-MM-DD`, quoted or not (FR-FMT-11). Anything else (impossible date, date-time, text) is not a due date for views and is shown as `Invalid due date` (AP-414).
- **Overdue:** open (Open or In progress), valid `due` earlier than today. Due today is not overdue. Done and Cancelled are never overdue. **(TZ):** "today" is the local date in the current zone; the `due` date is never shifted by a zone.
- **Due label:** today `Today`, tomorrow `Tomorrow`, overdue by one day `<date> · Yesterday`, overdue by n ≥ 2 days `<date> · <n> days overdue` (plural forms), otherwise `<date>`; `<date>` is the region's short weekday, day and short month (`Intl.DateTimeFormat(region, { weekday: 'short', day: 'numeric', month: 'short' })`).
- **Priority rank:** the option's position in the Task type's `priority` options; a missing value or a value that isn't an option ranks after the last option (AP-407).
- **Completed instant:** `completed` read as an instant (a value without offset in the machine's zone, as D-365); a date alone is that local day at 00:00.
