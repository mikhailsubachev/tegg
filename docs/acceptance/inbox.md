### R61. Membership, order and groups (FR-INB-01, -03; AP-482, AP-483)

- **Member** (AP-482): an indexed object outside `_templates/` and `.trash/` with frontmatter, whose `review` value is exactly `unreviewed` (a string after NFC and trimming, plain or quoted), whatever its type and whether its type's workflow is on; **or** whose type is Quick Note or Daily Note (locked, FR-TYP-12) and whose `review` is missing or any value other than `reviewed`. A virtual Daily Note is never a member. The type is matched by D-239.
- **Inbox instant:** a valid `captured` date-time, else `created`, else `modified`; a value without an offset is read in the machine's zone (D-365); a date alone is local 00:00 of that day; otherwise none.
- **Order:** instant descending; items without an instant last; ties, and items without an instant, by title (D-122 collation), then by NFC path byte order.
- **Groups,** by the local date of the instant in the current zone: `Today`; `Yesterday`; `Earlier this week` (from the region's first weekday, D-329, to the day before yesterday); `Older` (everything before, and items without an instant).
