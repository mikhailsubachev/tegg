# Acceptance Criteria: Object previews (v1.0 slice P)

See [README](README.md) for conventions. Release v1.0 (BRD §11), slice **P "Object previews"**, the first slice of the local graph (D-919; plan `docs/plans/v1-local-graph-plan.md` §2, §3, §5 B5). Until now every click on a reference opened it (D-140 for links, D-423 for embeds, D-486 for the source chip, D-368 for backlinks). Slice P adds the content-first preview popover (D-37, D-38): by default a single click on a link, embed or object row shows what the object is about, a double-click (or `Open`, ⏎ in the popover, ⌘↩) opens it. A global setting switches to *hover to preview, click to open* or *off: click opens* (FR-LNK-12, FR-SET-07). The editor gets the link context menu `Edit link` / `Remove link` and ⌥Space (FR-LNK-13). The graph (G1, G2) reuses this preview unchanged and adds one line (D-917); graph nodes are out of this slice. Slice P writes nothing to the vault, ever, except what `Edit link` and `Remove link` change in the open note; the setting and the preview size are machine-local. Exit goal: the owner reads a linked note without leaving the one they are in.

**Status: accepted, 2026-10-28.** AP-803…AP-826 (end of this file) were accepted by the owner as proposed: D-921…D-944 (BRD v1.110; AP-803 → D-921 … AP-826 → D-944). The AC-test changes at the end are approved as a whole (D-943) and are applied in slice P's build commit with the `AC-Test-Change` trailer. The layout values of R102 follow the board `design/edit-note-page/ObjectPreview.dc.html` (and `ObjectPreviewDark`, D-921). Contract: `docs/contracts/v1-previews.md`.

**Scope.** FR-LNK-08 (click to preview everywhere objects are referenced, except graph nodes), FR-LNK-09 (embeds), FR-LNK-10 (content), FR-LNK-11 (behaviour), FR-LNK-12 (the three modes), FR-LNK-13 (editor interplay), FR-NAV-08, FR-SET-07, the source-chip part of FR-TSK-08 ("click previews the source; double-click opens it scrolled to the embed"), and slice P's checks of FR-SYN-06, FR-UX-03, FR-UX-05 and NFR-OTH-02. **Out of scope:** graph nodes and the graph's preview column and popover (FR-GRP-03, -06: G1, G2; this slice only provides the extra header line D-917 needs, FR-LNK-10 AC-16); hover mode in the graph and its ring fill (G3, D-917); tabs, so ⌘-click and ⌘-double-click don't open a new tab yet (FR-NAV-06, AP-807); editing inside the popover (FR-LNK-11: phase C); the AI summary at the top of a preview (FR-LNK-10: phase C); saved query views (FR-QRY: v1.0, not built; when built they follow the list-row rules of R104 row 9); unlinked mentions (FR-LNK-05, v1.x); full-size image viewing (FR-ATT-03, v1.0, its own slice).

### R103. What each input does (FR-LNK-11, FR-LNK-12, FR-LNK-13; AP-807, AP-810, AP-811, AP-824)

| ⌘-click, ⌘-double-click | open in the current view until tabs (AP-807) | same | same |
| Pointer resting on it for the delay | nothing | preview (AP-824) | nothing |
