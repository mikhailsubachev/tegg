# Acceptance Criteria: Backlinks and link states (MS4 slice 4A)

See [README](README.md) for conventions. Milestone MS4 (BRD §11.2), slice **4A "Backlinks and link states"** (D-267; plan `docs/plans/ms4-implementation-plan.md` §3). The right panel's Backlinks tab stops being a placeholder: every note shows which objects link to it, grouped by type, with the text around each link and the attribute name for links from properties. Broken links stop doing nothing (D-142): activating one offers to create the note. Duplicate titles become distinguishable in every object picker, and two vault checks list broken links and duplicate titles. 4A writes only the notes the user creates from a broken link (plan §5). Exit goal: the owner sees what links to a note and fixes broken links by creating the note.

**Status: accepted, 2026-10-15.** AP-204…AP-223 (end of this file) were accepted as recommended: D-276…D-295 (BRD v1.45).

**Follow-up (slice 4B preview feedback, 2026-10-16; `docs/feedback/ms4-4b.md`).** D-368 (F2): the panel shows one chip per linking object, grouped and sorted as before, with no excerpts, attribute labels, embed markers or `Show <n> more`; activating a chip opens the source like any open. FR-LNK-01 AC-4…AC-6 and FR-LNK-02 AC-4…AC-6 are superseded (text kept), the new criteria are FR-LNK-01 AC-17…AC-21 and FR-LNK-02 AC-7; R15 and the excerpt parts of AC-9, AC-11, AC-12, AC-14 and AC-15 are annotated. The Broken links page keeps its excerpts (FR-LNK-04 AC-10). D-367 (F1): the note made by a broken link's `Create` opens with the caret at the end of its title, not in its body (FR-LNK-04 AC-5 annotated; editor.md FR-EDT-01 AC-13).

**Scope.** FR-LNK-01 (backlinks panel), FR-LNK-02 (the panel part: attribute names and embeds; extraction and index are types.md FR-LNK-02 AC-1…AC-3), FR-LNK-04 (broken links: offer, Create, the Broken links list), FR-LNK-07 (the link part: one chip style everywhere, broken style), FR-LNK-14 (AC-3 distinguishing details, AC-4 the Duplicate titles check), and the 4A part of FR-SYN-06. **Out of scope:** rendering embeds and the embed frame and broken-embed style (FR-EMB-01, -02, -04, FR-LNK-07 embed part: 4F); date links to missing Daily Notes, virtual Daily Notes and date mentions in a Daily Note's backlinks (FR-DLY-08 AC-1…AC-3: 4B; 4A covers backlinks of Daily Notes that exist as files); renames and link rewrites (FR-LNK-03, FR-FMT-08: 4C); merging duplicates (the job itself, AP-218: 4C); Tag objects and tag pages (FR-TAG: 4D; inline `#tags` and `tags:` aren't links, AP-206); backlinks of Image and PDF objects through `![[file.png]]` (FR-ATT-07 AC-2: MS6); previews and popovers (FR-LNK-08…13: v1.0); unlinked mentions (FR-LNK-05: v1.x, AP-211); empty-state polish beyond the one message (FR-UX-06: MS8); block ids and checking that a `#Heading` or `#^id` exists (FR-LNK-06: v1.0).
