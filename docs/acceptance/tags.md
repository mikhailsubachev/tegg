# Acceptance Criteria: Tags (MS4 slice 4D-lite)

See [README](README.md) for conventions. Milestone MS4 requirements built in the daily-use order after 6A (BRD §11.2; `docs/plans/mvp-daily-use-plan.md` §3; D-370, D-690…D-710). Tags become objects you can open: **All tags** (`tags`) lists every tag with its count and last use; a **tag page** (`tag/<key>`) lists every object with the tag in one table (board `design/edit-note-page/TagPage.dc.html`; All tags: `TagsAll.dc.html`, table only, D-704); the sidebar's **Tags section** shows the five most recently used tags; tags can be **created** (`New tag`, a Tag file in `Tags/`), **renamed** and **deleted** (`tag-rename` and `tag-delete` jobs of `docs/contracts/ms4-jobs.md`, backup zip first, D-269), and given a **colour** that every tag surface shows (D-707…D-709). Search gets a tag filter (D-706). The slice also ships the **Settings › Backups** restore UI (D-396) and the Duplicate titles **`Merge…`** UI (D-290, D-392), both from D-705, without a board. Where a board and a decision differ, the decision wins: no description anywhere (D-691), no Cards tab (D-704), the colour (not drawn on the boards) follows D-707…D-710.

**Status: approved, 2026-10-22.** Points AP-650…AP-667 (end of this file) are decided by the owner as D-711…D-728 (BRD v1.87), each as recommended; a criterion naming an AP follows that decision. D-729 approves the changes to earlier criteria listed here.

## Reference tables

### R79. Derived values (D-694, D-701; AP-650, AP-660)

- **Tag:** a key with at least one occurrence in an object outside `_templates/` and `.trash/`, or a Tag file. **Virtual** = no Tag file (FR-TAG-03).
- **Tag file:** an object with `type: tag` (FR-TYP-13 matching) in `Tags/`, outside `.trash/` (AP-658 for other folders). It belongs to the key of its `title`, or of its file stem when `title` is missing. Two or more files for one key: the oldest valid `created` wins, then path order (NFC, byte order); the others are listed on Duplicate titles and have no effect on the tag (AP-657).
- **Display name** (heading, chips, sidebar, All tags, suggestions): the Tag file's title (stem when missing) when there is a file; else the most frequent written spelling, ties by code point (D-185) (AP-650).
- **Count:** the number of objects outside `_templates/` and `.trash/` with at least one occurrence; one per object, whatever the number of occurrences; done and cancelled tasks count (D-701).
- **Last used:** the newest `modified` instant among the counted objects (as FR-TYP-09's Modified), shown in the type page's Modified format; empty for count 0 and for a tag none of whose objects has a valid `modified` (AP-660).
- **Colour:** the winning Tag file's `color` when it is one of the eight R14 tokens (D-236); `None` (neutral chip) when missing, empty, unknown (`magenta`) or for a virtual tag (D-707).
- **Index:** all of the above come from the index (one query each, never from reading notes) and are rebuilt from the files (AR-01).
