# Acceptance Criteria: G3 in the panel (v1.0 follow-up slice "G3 in the panel")

See [README](README.md) for conventions. Release v1.0 (BRD §11), a small follow-up slice after **G2** ([graph-panel.md](graph-panel.md), the right panel's Graph tab, merged in PR #94) and **G3** ([graph.md](graph.md) part two, presets, keyboard, List, hover and Off, written against the full view only). After the merge, `GraphPanel` mounts the shared `GraphCanvas` without G3's props (contract `docs/contracts/v1-graph.md` §16.11 "Merged after G2"), so the panel has no tab stop, focus ring, hover ring, keyboard map, preset control or `Graph` / `List` switch. This slice hooks G3's pieces up in the panel, as listed in graph.md's [Seams: what G3 leaves for G2](graph.md#seams-what-g3-leaves-for-g2) and graph-panel.md's [Seams: what G2 leaves for G3](graph-panel.md#seams-what-g2-leaves-for-g3). Exit goal: everything the owner can do with presets, the keyboard, the List and the preview modes in the full view, they can do in the panel beside the note, and the panel's preset writes are as safe as the full view's.

**Status: approved, 2026-10-30.** The owner accepted AP-960…AP-974 (end of this file) as proposed: D-1130…D-1144 (BRD v1.122; AP-n → D-(n+170)); criteria that depend on one cite it. Contract: `docs/contracts/v1-graph.md` §17.

**Scope.** FR-GRP-02 (presets in the panel), FR-GRP-01 and FR-GRP-06 (the hand-over and the preview from List rows), FR-LNK-12 in the panel (click, hover, Off), FR-UX-03 (the keyboard map and R123's commands in the panel), FR-UX-08 (the List, VoiceOver descriptions, the focus ring, Reduce motion in the panel), and this slice's checks of FR-SYN-03 / NFR-REL-02, FR-SYN-06, FR-UX-05 and NFR-OTH-02. Reference tables R125…R128. **Reused by reference, not repeated:** where the panel behaves exactly as the full view, a criterion here names the G3 criterion and states only the panel's setup and what differs; G3's own tests stay on the full view. **Out of scope:** anything in the full view (G3, unchanged); tabs (FR-NAV-06, D-970); the global graph (FR-GRP-04).

**Risk tiers** (test-strategy §3). This slice makes the panel the second place that **writes a vault file** (`.tegg/graph.yml`), so its top risk is **T1, data loss in `graph.yml`**: a preset action from the panel overwriting an external or synced change, rewriting an unreadable file, or writing when nothing changed; those criteria are marked **(T1)** and check bytes, mtime and inode as G3's do. Next is **T2, silently wrong data**: the panel applying other filters than the preset names, a wrong `· modified` in one view after an action in the other, a List tree that differs from the panel canvas, a description that reads the wrong position, or the panel's preset or view leaking into the full view through the hand-over.

**Test layers:** as [graph-panel.md](graph-panel.md) and graph.md part two (L1, L4, L5, L6, manual); no new layer, no new IPC command, no Rust change. L5 uses the G1 fake core with G3's presets twin (`fake-presets.ts`, contract §16.6): `graphCalls()`, `presetCalls()`, `presetsFail(kind)`, `setFile('.tegg/graph.yml', …, { silent: true })` (D-1110), `writes()`, `uiState()`.

**Test clock** (L5, L6 with `TEGG_TEST=1`): as graph-panel.md (`2026-10-28T10:00:00+01:00`, Europe/Prague, region `en-US`, Object preview *Click to preview* with the delay 400 ms *(changed by D-1164: the product default is now hover with 1,000 ms, so the mode is stored as `click` (previews.md part three's test rule) and the 400 ms by each test that uses hover)*, `rightPanel: { open: true, tab: 'graph', width: 288 }`, window 1,440 × 980 with the sidebar open, so the panel's canvas is 260 px wide), `ui-state.json` without a `graph` entry unless stated. Hover tests run the hover controller's timers on the page clock (`page.clock.install`, D-1118). Each criterion names a suggested test name (`Test:`); a test may split a criterion into several tests with the same prefix.

**Fixtures:** `tests/fixtures/vaults/graph/` unchanged (its short names, runtime files and hub; the panel's counts in its README section "Panel (G2)"), and `tests/fixtures/graph-presets/` unchanged: "with `valid`" means `valid.yml` copied to `.tegg/graph.yml` of the temporary vault before the app opens it (likewise `invalid-yaml`, `newer-version`, `unknown-keys`), as graph.md part two. The centre is Plán (`Pages/Plán čtvrtletí.md`) at depth 1 unless stated. No new fixture file.
