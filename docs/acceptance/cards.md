# Acceptance Criteria: Object cards, property icons and the icon picker (v1.0 slice OC)

See [README](README.md) for conventions. Slice **OC** (plan `docs/plans/oc-object-cards-and-settings-plan.md`; D-2054…D-2074, BRD v1.238, v1.239), built now and released as **0.6.0** (D-2073). One card for every type (`ObjectCard`), the `Card` section of type settings with `card:` in the type file, property icons, and the Lucide icon picker. The type-settings layout and its `Views` section are in [types.md](types.md) (FR-TYP-01 AC-22…AC-28), board cards in [views.md](views.md) part four, card embeds in [embeds.md](embeds.md) (FR-EMB-02 AC-19…AC-21), the preview strip in [previews.md](previews.md) part four, and the Settings layout in [app-shell.md](app-shell.md) (FR-UX-02 AC-22…AC-26, R219).

Boards: `design/edit-note-page/TypeCards` (A, the card for every type), `CardSettings` (A all type settings on one page, B card defaults per type, D property icons, E searching icons), `IconSet`, `Settings`, `SettingsApp`, and their Dark variants. **Board `CardSettings` section C holds the owner's own project data** (D-2074): it may be looked at for layout only; its names, titles, values and text are never copied into criteria, fixtures, tests or code. Where a board note differs from D-2054…D-2073, the decisions win (D-2074).

**Status: approved, 2026-11-22.** AP-1571…AP-1604 (end of this file) are decided as proposed (owner: "Accept all proposals"): D-2076…D-2109, BRD v1.241.

Decisions this file carries out:
- **D-2054** the card replaces Preview properties: Title always, plus any properties, in order, no limit; board cards, card embeds, previews and link hovers use it (amends D-1891, D-1904: their `preview` becomes `card`). **D-2055** no card per view. **D-2056** the type icon is always on the card (Task: its checkbox). **D-2057** `CardAnatomy` archived. **D-2058** no Columns section in type settings.
- **D-2059** `card: [keys]` in the type file (attribute keys plus `tags`, `body`, `description`, `source`, `aliases`, `created`, `modified`); without it `tags, body, <preview keys>, modified`, system types per board `CardSettings` B; nothing written until the Card section is changed; `preview:` kept byte for byte and no longer read; an unknown key kept and ignored. **D-2060** `version:` unchanged.
- **D-2061** at most 2 rows of pills, then `+N more`. **D-2062** `description` when set; `body` the first plain text after the headings, 2 lines. **D-2063** no `Day summary`; Image and PDF show the attributes they have; `Size` and `Embedded in` only if the index holds them. **D-2064** URL values: host and last path segment; a `file://` folder as `↗` and its name; nothing fetched. **D-2065** no value, or only `—`, draws nothing.
- **D-2066** Recent icons: the last 12 on this Mac. **D-2067** the 24 old icon names keep drawing through an alias table; files aren't rewritten. **D-2068** previews and link hovers show the card's pills and link chip. **D-2069** no card in Pinned. **D-2070** property icons (`icon:` on the attribute, a Lucide name), the picker with Lucide 0.460 (1,539 icons, ISC), bundled, also for the type icon. **D-2071** Settings and type settings share one layout; nothing added, removed or changed; type settings' `Views` lists real views.

**Scope.** FR-TYP-11 (the card, its defaults, the `Card` section), FR-TYP-01 (property icons, the icon picker, the type icon), FR-TYP-12 (the `Unreviewed` pill), AR-07, FR-LNK-14 (the duplicate details line, AP-1589), and this slice's pieces of FR-FMT-07, FR-FMT-12, FR-SYN-02, FR-SYN-03, FR-SYN-06, FR-STO-07, NFR-POR-01, NFR-PERF-07, NFR-SEC-01 (inside FR-TYP-01 AC-20), FR-UX-03, FR-UX-05, FR-UX-08, NFR-OTH-02. Reference tables R209…R218.

**Out of scope.** Templates, Font, Font size, Accent color, Trash and history, shortcut editing (they stay `Coming in v1.0`); a card setup per view (D-2055); a Columns section in type settings (D-2058); Daily Note's `Day summary` (D-2063); a card in Pinned (D-2069); `Embedded in` unless AP-1577 brings it in; editing values on a card (except Task's checkbox, D-1904, and the board's drags, views.md R187); Inbox cards (AP-1590); type-page tables, List views and search rows (they aren't cards); computed entries of any kind.

**Risk tiers (test-strategy §3).**
- **T1, data loss:** every type-file write of this slice (`card:`, an attribute's `icon:`, the type's `icon:`): one minimal atomic write, refused on an external change, `preview:` and every other line byte-identical; **the upgrade**: opening a 0.5.x vault writes no type file (FR-SYN-06); a property delete that leaves a stale key or drops another one. Marked **(T1)**, checked by bytes, mtime and inode.
- **T2, silently wrong data:** a card that shows another type's list, a value under the wrong name, an empty value drawn or a set one hidden (`—`, `[]`, `false`, NFD keys), a `+N more` count that doesn't match what is hidden, a footer date shifted by a time zone, a URL chip that names another host, an old icon name drawn as the generic icon, the Task card losing D-1904's rules. Marked **(T2)**, checked against R218.
- T3: the Card section and the picker as a workflow. T4: layout, themes, accessibility.

**Shared definitions.**
- **Card list** of a type: its `card:` value when the key is present and readable (R209), else R210's default list.
- **Effective keys**: the card list without unknown keys, repeated keys (the first kept), `title`, and keys R212 doesn't draw (`review`, `file`-kind attributes, AP-1592).
- **ObjectCard**: the one card component of plan §4.2, an `article` with `data-object-card` and `data-path` (R211).
- **Pill area**: the part of a card between the text and the footer (R211). A **pill** is one element of it with `data-attribute` (R212).
- **Empty value**: R212's last row.
- **Inbox member**: inbox.md's rule (D-600), the same that draws the amber dot in frames (embeds.md FR-EMB-02 AC-18).
