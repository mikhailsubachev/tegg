# Tegg Preview: MS3 slice 3D.1 "Your 3D feedback"

Build: `main` at the merge of PR #32, installed as `~/Applications/Tegg Preview.app` (`cd app && npm run app:preview`).
Its data stays in `~/Library/Application Support/Tegg Preview/`, separate from test runs (D-118).

This build edits notes and type files, as 3D did: atomic writes, read back before replacing, never over a change made by another app. Use a vault with a backup, or a generated or new one.

## What's new

- **Search** finds file names too. A result found only by its file name shows `File name: …`. Several words rank the exact phrase first, then notes with all the words, then notes with any of them; quotes and `-word` still work (D-246, D-253, D-254).
- **Opening a note** puts the caret at the start of its first editable block, without scrolling; Back keeps your scroll position. A new note opens with its title ready to edit; ⏎ moves to the body (D-247, D-255).
- **Source** is plain text on every type (D-248).
- **Links in properties**: Description, Source, and Text and Long text properties can hold `[[links]]`. Out of editing they show as chips that open the note; they count as links and backlinks (D-249, D-257).
- **`@` inserts a link** like `[[`, at the start of a word, in the body and in those property fields. A space when nothing matches closes the list and leaves `@word` as text; make multi-word new notes with `[[` (D-250, D-258, D-263).
- **Create type**: the page of a type value without a definition (for example `idea` in the generated vault) has `Create type "idea"`, which writes only the type file (D-251, D-259).
- **Columns** on a type page replaces `Add column`: check or uncheck properties to show, up to 4; `New property…` is in the same menu (D-252, D-260).
- **Fixed**: an e-mail address typed into a note wasn't saved.
- Keyboard focus on the note body shows a ring (D-264); Esc in focus mode leaves it (D-265).

## Known limits

- Opening a very long note takes about 0.2 s from the switcher (target 0.11 s on the reference machine).
- `@` creates one-word notes only (D-263).
- Other properties are still read-only.

## 15-minute charter

Use the generated vault (`tools/gen-vault`) or a new Starter vault.

1. ⌘⇧F: search for a word that is only in a file name, then for two words that appear together in one note and apart in another. Is the order right?
2. Open notes from the switcher, a link and a type page. Is the caret where you'd start typing? Go Back: is the scroll kept?
3. On a note, write `Viz [[…]]` in Description and a plain text in Source. Click away: chips? Does the backlink show on the target?
4. In a paragraph type `@` and part of a title; pick it. Try `eva@example.com` in text: no list, and is it saved?
5. Open `idea` (or another undefined type) and use `Create type`. Does the note now show its properties panel?
6. On a type page, use `Columns` to add and remove columns. Did only the type file change?
7. Open the vault in Obsidian (copy): do the property values with links read correctly (FR-EDT-07 AC-19)?
8. Write down anything wrong, confusing or slow.

Feedback: `docs/feedback/ms3-3d1.md` or a GitHub issue labelled `dogfood`.
