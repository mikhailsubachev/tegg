## Cause of F1

- The editor adds no empty paragraph at the end of a note (`trailingNode: false` in `packages/editor/src/schema.ts`):
  it would write an empty line into every file (FR-FMT-07, FR-SYN-06). So when the last block is a code block, there
  is no text block below it to click into.
- TipTap's code block leaves the block only on **three** ⏎ at its end (two empty lines, then ⏎) or on ↓ at the end of
  the last block. Neither is discoverable; a single ⏎ adds a line inside the code, as it should.
- The block handle's `Add block below` (FR-EDT-01 AC-3) works, but only on hover, left of the block.

The same applies to every block the caret can't leave by typing: a table, a callout, a mindmap, an embed, a divider.
