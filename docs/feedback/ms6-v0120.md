## Cause of F2

The title bar's tab strip had the class `tabs`, which the page-level segmented tabs (Tasks, since 5A-1) also use. Their
rule (`styles.css`, `.tabs { … margin: 0 12px 12px 0; background: var(--hover) }`) came later in the file and gave the
strip a 12 px bottom margin and a grey background, so the tab sat 6.5 px above the centre of the 44 px bar. The strip
now has its own class `titlebar-tabs`.

## Cause of F5

⏎ then Tab after `- druhá` makes an empty item nested under it. The editor wrote it as a bare marker on the next line
(`- druhá` / `  -`). Markdown reads a lone `-` right under a paragraph as a setext heading underline (and `1.` as more
text), so the saved file would turn `druhá` into a heading. The save check saw the change of structure and refused the
write, so nothing was saved until the item had text. Only this shape is affected: an empty item that **opens** a
nested list right under its parent's text. An empty top-level item (`bug_4a`) and an empty later item are written as
before.
